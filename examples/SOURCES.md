# Источники примеров

Выбраны два прибора из предоставленного пользователем файла
«Вставленный текст(2).txt», выгрузки каталога «СОЮЗ-ПРИБОР».
В задании не были выделены конкретные две позиции; пользователь разрешил выбрать их.

| Товар | Производитель | Артикул | Ссылка в исходной выгрузке |
| --- | --- | --- | --- |
| testo 510 дифференциальный манометр | Testo | 0563 0510 | https://www.souz-pribor.ru/product/testo-510/ |
| testo 511 абсолютный манометр | Testo | 0560 0511 | https://www.souz-pribor.ru/product/testo-511/ |

Названия, производитель и артикулы перенесены из выгрузки. Тип прибора дословно
выделен из названия. Характеристики с сайтов не загружались и не добавлялись
по памяти. Цена, изображение и внутренние идентификаторы каталога не используются.

Паспортные данные в этих записях отсутствуют: description оставлен пустым.
expected_specs — список вопросов редактора, а не утверждения о свойствах приборов.
Поэтому оба примера намеренно показывают работу с неполным источником.
Содержательный текст описывает известный тип измерения и вопросы для подбора;
это черновик, который нельзя считать заменой технического паспорта.

Файлы `*.content.json` — ответы, подготовленные ChatGPT в этой рабочей сессии
по экспортированному промпту. Это реальные сохранённые примеры ручного режима,
а не ответы, полученные через OpenAI API. `*.result.json` и `*.md` сформированы
приложением после проверки и сохранения через API (в этой среде — в тестовой SQLite;
при штатном запуске — в PostgreSQL). Повторная загрузка примера
воспроизводит этот ответ и не вызывает модель заново.
